在安卓手机上运行本地 AI 模型

DeepSeek Harness 移动端是一款免费开源应用，内置 0.5B 量化模型，可在完全离线环境下进行 AI 对话和文本生成。同时支持配置在线 API，在有网络时切换到更大的模型。

功能说明

本地离线推理

内置 0.5B 量化模型，无需网络连接即可使用。适合简单对话、文本生成和基础问答。

在线 API 切换

支持 DeepSeek、OpenAI 等兼容 OpenAI 格式的 API 服务，可在设置中配置地址、密钥和模型名称。

双架构支持

同时支持 arm64-v8a（64位）和 armeabi-v7a（32位）架构，老旧设备也可运行。

局域网访问

服务启动后生成局域网访问地址，同一 Wi-Fi 网络下的其他设备（电脑、平板）也可访问使用。

基础 Linux 环境

内置基础 Linux 命令和目录结构，支持文件操作、脚本执行和常用网络工具。

沙箱工作目录

在外部存储创建独立工作文件夹（/storage/emulated/0/DeepSeek Harness），AI 操作被限制在该目录范围内。

使用步骤

1

安装应用

下载 APK 文件后点击安装，如提示未知来源，请在系统设置中允许安装。

2

授予权限

首次启动时授予存储权限，建议同时允许电池优化白名单以保持后台运行。

3

等待初始化

首次启动会自动解压应用文件和 AI 模型，中配设备约需 2 至 3 分钟，期间请勿关闭应用。

4

启动服务

初始化完成后 Node.js 服务自动启动，界面显示本地和局域网访问地址。

5

开始使用

应用内 WebView 自动加载操作界面，可直接开始对话。也可在其他设备浏览器中输入局域网地址访问。

6

配置设置

点击右上角设置按钮，可配置在线 API 地址和密钥、切换本地或在线模型、检测应用更新。
