在手机上运行 AI Agent

DeepSeek Harness 移动端，让你在安卓设备上直接运行本地 AI 模型，支持离线推理和在线 API 切换。

立即下载 GitHub

功能特性

本地离线推理

内置 0.5B 量化模型，无需网络即可进行 AI 对话和推理。

在线 API 切换

支持配置 DeepSeek、OpenAI 等兼容 API，有网络时可切换到更大模型。

32/64 位支持

同时支持 armeabi-v7a 和 arm64-v8a 架构，老旧设备也能运行。

局域网访问

服务启动后生成局域网链接，同一网络下的其他设备也可访问使用。

简易 Linux 终端

内置基础 Linux 命令环境，支持文件操作和脚本执行。

工作文件夹沙箱

在 /storage/emulated/0/DeepSeek Harness 下创建独立工作目录，限制操作范围。

系统要求

  • Android 7.0 (API 24) 及以上
  • ARM 64位 (arm64-v8a) 或 ARM 32位 (armeabi-v7a)
  • 至少 2GB 可用存储空间
  • 建议 4GB 以上运行内存
  • 首次启动需要 1-5 分钟初始化（取决于设备性能）

使用说明

安装应用

下载 APK 文件后，在手机上点击安装。如果提示"未知来源"，请在设置中允许安装。

授予权限

首次启动时，授予存储权限和电池优化白名单，确保服务能在后台稳定运行。

等待初始化

首次启动会自动解压应用文件和 AI 模型，进度条显示当前进度。中配设备约需 2-3 分钟。

启动服务

初始化完成后，Node.js 服务自动启动，显示局域网访问链接。

开始使用

在应用内 WebView 或浏览器中打开链接，即可开始与 AI 对话。也可在同一局域网的其他设备上访问。

配置设置

点击右上角"设置"，可配置在线 API 地址和密钥、切换本地/在线模型、启用动态壁纸、检测更新。
