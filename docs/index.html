功能特性

本地模型推理

内置0.5B参数模型，完全离线运行，无需网络即可进行AI对话和文本生成。

在线API支持

兼容DeepSeek及OpenAI格式API，可在设置中配置API地址、密钥和模型名称。

双架构支持

同时支持arm64-v8a（64位）和armeabi-v7a（32位）架构，覆盖新旧安卓设备。

局域网访问

启动后生成局域网访问地址，同一网络下的其他设备可通过浏览器访问使用。

检测更新

设置中一键检测最新版本，有更新时弹窗提示，可直接跳转下载页面。

沙箱工作目录

在/storage/emulated/0/创建独立工作目录，AI操作限制在目录范围内，保护系统安全。

系统要求

操作系统Android 7.0 及以上（API Level 24+）
处理器架构arm64-v8a（64位）/ armeabi-v7a（32位）
存储空间至少 2GB 可用空间（安装包746MB，解压后约1.5GB）
运行内存建议 3GB 及以上
网络本地模型无需网络；在线API需联网

使用手册

安装应用

下载APK文件后，在手机上点击安装。如提示"未知来源"，请在设置中允许安装未知来源应用。

首次启动初始化

首次启动会自动解压运行时文件和本地模型，进度条实时显示进度。高配手机约1-2分钟，中配约5-10分钟，低配可能需要更长时间。请耐心等待，不要关闭应用。

开始使用

初始化完成后自动进入主界面。默认使用本地离线模型，可直接在输入框发送消息进行AI对话。

配置在线API（可选）

点击右上角设置按钮，填写API地址（如https://api.deepseek.com/v1）、API密钥和模型名称（如deepseek-chat）。模型模式选择"在线"或"自动"即可使用在线API。

局域网访问

服务启动后，主界面显示局域网访问地址。同一WiFi网络下的其他设备（手机、电脑）可在浏览器中输入该地址使用AI服务。

检测更新

在设置页面点击"检测更新"按钮，应用会自动检查GitHub Release最新版本。有更新时弹窗提示，可选择立即更新或暂不更新。
