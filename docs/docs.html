1. 产品简介

DeepSeek Harness 移动端是一个将 DeepSeek Harness（Node.js AI Agent 框架）移植到安卓平台的应用。它允许用户在手机上直接运行本地 AI 模型，支持离线推理，同时也支持配置在线 API 切换到更大的模型。

应用内置了 Node.js 运行时、0.5B 量化 AI 模型和基础 Linux 命令环境，首次启动后自动初始化，无需用户手动配置即可使用。

3. 安装指南

3.1 下载 APK

从 GitHub Release 页面下载最新版本的 APK 文件：

https://github.com/ETQWFD/deepseek-harness-mobile/releases

3.2 允许未知来源

在手机设置中，允许浏览器或文件管理器安装未知来源的应用。路径通常为：设置 → 安全 → 未知来源应用安装。

3.3 安装

点击下载的 APK 文件，按照提示完成安装。安装过程可能需要 1-2 分钟。

4. 快速开始

  1. 启动应用：点击应用图标启动 DeepSeek Harness。
  2. 授予权限：首次启动会请求存储权限，请点击允许。同时会请求电池优化白名单，建议允许以确保后台稳定运行。
  3. 等待初始化：首次启动会自动解压应用文件和 AI 模型。进度条显示当前进度，中配设备约需 2-3 分钟，低配设备可能需要 5-10 分钟。
  4. 服务启动：初始化完成后，Node.js 服务自动启动，屏幕显示局域网访问链接。
  5. 开始使用：应用内 WebView 会自动加载界面，你可以直接开始与 AI 对话。

重要：首次初始化期间请勿关闭应用或锁屏，否则可能导致解压失败。如遇失败，可在应用信息中清除数据后重新启动。

5. 设置配置

点击主界面右上角的"设置"按钮进入设置页面。

5.1 模型模式

  • 自动：有网络且配置了在线 API 时使用在线模型，否则使用本地模型。
  • 仅本地：始终使用内置的 0.5B 本地模型，无需网络。
  • 仅在线：始终使用配置的在线 API，需要网络连接。

5.2 在线 API 配置

字段说明示例
API 地址兼容 OpenAI 格式的 API 端点https://api.deepseek.com/v1
API 密钥你的 API 密钥sk-xxxxxxxx
模型名称要使用的模型 IDdeepseek-chat

5.3 动态壁纸

勾选"启用动态壁纸"后，主界面背景会每分钟更换一张二次元美女壁纸，半透明显示。此功能需要网络连接。

5.4 检测更新

点击"检测更新"按钮，应用会连接 GitHub Release 检查是否有新版本。如有更新，会弹出对话框提示，可选择立即更新或暂不更新。

6. 本地模型

应用内置了一个 0.5B 参数的量化模型（Q4_K_M 格式，约 470MB），可在完全离线的环境下运行。

6.1 模型特点

  • 参数量：0.5B
  • 量化格式：GGUF Q4_K_M
  • 文件大小：约 470MB
  • 推理速度：中配设备约 5-10 token/s
  • 适用场景：简单对话、文本生成、基础问答

6.2 使用本地模型

在设置中将模型模式设为"仅本地"或"自动"（无网络时），即可使用本地模型。本地模型的响应速度取决于设备性能，建议在 64 位设备上使用以获得更好体验。

提示：本地模型能力有限，适合简单任务。如需更复杂的推理，建议配置在线 API 使用更大的模型。

7. 在线 API

应用支持兼容 OpenAI 格式的在线 API，可配置 DeepSeek、OpenAI、通义千问等服务。

7.1 配置步骤

  1. 进入设置页面
  2. 在"API 地址"字段输入 API 端点（需包含 /v1）
  3. 在"API 密钥"字段输入你的密钥
  4. 在"模型名称"字段输入要使用的模型 ID
  5. 将模型模式设为"仅在线"或"自动"
  6. 返回主界面，服务会自动使用在线 API

7.2 常用 API 配置

智谱清言https://open.bigmodel.cn/api/paas/v4glm-4

8. Linux 终端

应用内置了基础 Linux 命令环境，可在 AI 对话中通过命令调用。

8.1 支持的命令

  • 文件操作：ls, cd, pwd, mkdir, rm, cp, mv, cat, echo, touch
  • 文本处理：grep, head, tail, wc, sort
  • 系统信息：uname, whoami, date, uptime
  • 网络工具：ping, curl, wget
  • 其他：chmod, find, tar, zip, unzip

8.2 环境变量

  • DSH_ROOT：应用根目录
  • DSH_WORK_DIR：工作文件夹路径
  • DSH_PLUGIN_DIR：插件目录路径
  • LLAMA_MODEL_PATH：本地模型文件路径
  • MODEL_MODE：当前模型模式（local/online/auto）

9. 工作文件夹

应用会在外部存储创建独立的工作文件夹：

/storage/emulated/0/DeepSeek Harness/

9.1 目录结构

  • plugins/：插件目录，用户可在此放置自定义插件
  • data/：数据目录，AI 生成的文件默认保存在此
  • logs/：日志目录，记录服务运行日志

9.2 沙箱限制

AI 的文件操作被限制在工作文件夹内，无法访问其他目录。如需访问其他位置，需用户手动授权。

10. 局域网访问

服务启动后，应用会显示局域网访问链接，同一 Wi-Fi 网络下的其他设备（手机、电脑、平板）也可访问使用。

10.1 获取链接

服务启动成功后，主界面会显示类似以下的链接：

http://192.168.1.100:8080

10.2 其他设备访问

  1. 确保其他设备连接到同一个 Wi-Fi 网络
  2. 在浏览器中输入显示的局域网链接
  3. 即可开始使用 AI 服务

提示：局域网访问不需要额外配置，但需确保手机防火墙未阻止对应端口。

11. 更新升级

11.1 检测更新

在设置页面点击"检测更新"，应用会连接 GitHub Release 检查最新版本。

11.2 安装更新

如有新版本，点击"立即更新"会跳转到 GitHub Release 页面，下载新 APK 后覆盖安装即可。

注意：覆盖安装不会清除已解压的应用文件和模型，但建议在更新前备份工作文件夹中的重要数据。

12. 故障排除

12.1 启动失败 (code=1)

原因：Node.js 运行时启动失败，可能是解压不完整或存储空间不足。

解决：

  1. 确保存储空间至少有 2GB 可用
  2. 在应用信息中点击"清除数据"
  3. 重新启动应用，等待初始化完成
  4. 如仍失败，尝试卸载后重新安装

12.2 初始化很慢

原因：首次启动需要解压约 500MB 的文件，低配设备可能需要较长时间。

解决：

  • 耐心等待，不要关闭应用或锁屏
  • 确保手机电量充足或连接充电器
  • 关闭其他后台应用释放内存
  • 64 位设备通常比 32 位设备快 2-3 倍

12.3 服务在后台被杀死

原因：系统电池优化限制了后台服务。

解决：

  1. 在首次启动时允许电池优化白名单
  2. 手动设置：设置 → 电池 → 应用启动管理 → 找到 DeepSeek Harness → 允许后台活动
  3. 将应用锁定在最近任务列表中

12.4 在线 API 无法使用

原因：API 地址、密钥或模型名称配置错误。

解决：

  • 检查 API 地址是否包含 /v1 后缀
  • 确认 API 密钥正确且有余额
  • 确认模型名称与服务商支持的模型 ID 一致
  • 测试网络连接是否正常

12.5 局域网无法访问

原因：设备不在同一网络或防火墙阻止端口。

解决：

  • 确保所有设备连接同一个 Wi-Fi
  • 检查手机是否开启了 VPN 或代理
  • 尝试关闭手机防火墙应用
  • 确认链接中的 IP 地址正确

13. 常见问题

Q: 应用完全免费吗？

A: 是的，本软件完全免费开源，采用 MIT 许可证。严禁倒卖或付费下载。

Q: 为什么 APK 这么大？

A: APK 中包含了 Node.js 运行时（约 80MB）、0.5B AI 模型（约 470MB）和应用文件，总计约 750MB。

Q: 可以更换更大的本地模型吗？

A: 当前版本内置固定的 0.5B 模型。如需更大模型，建议使用在线 API。后续版本可能支持自定义模型。

Q: 支持 iOS 吗？

A: 目前仅支持 Android。iOS 版本暂无计划。

Q: 如何报告 bug 或提出建议？

A: 请在 GitHub 仓库提交 Issue：https://github.com/ETQWFD/deepseek-harness-mobile/issues

Q: 应用会收集我的数据吗？

A: 不会。所有数据都存储在本地，应用不会上传任何用户数据。在线 API 模式下，对话内容会发送到你配置的 API 服务商。
