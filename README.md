# DeepSeek Harness 移动端

DeepSeek Harness Android 客户端 - 离线AI助手，支持本地模型推理。

## 特性

- 🤖 **本地模型推理**：内置 0.5B 模型，完全离线使用
- 🔄 **模型切换**：支持自动/本地/在线三种模式
- 📱 **双架构支持**：arm64-v8a (64位) + armeabi-v7a (32位)
- 🔒 **ETC+KU 加固**：R8 代码混淆优化
- 🌙 **暗黑模式**：支持星空背景图
- 🔌 **插件系统**：可扩展功能
- 🖥️ **局域网访问**：启动后可通过局域网访问
- 📦 **沙箱环境**：工作目录隔离，安全可靠

## 版本

当前版本：v2.37 · ETC+KU终极版

## 系统要求

- Android 7.0+ (API 24+)
- arm64-v8a 或 armeabi-v7a 架构
- 至少 1GB 可用存储空间

```bash
# 克隆仓库
```
